# 数字逻辑电路（Digital Logic Circuit）

类 Logisim 的数字逻辑电路绘制与仿真工具。基于 C++17 与 wxWidgets 3.2 开发，运行于 Windows（Visual Studio 2022，x64）。

从左侧元件树选择逻辑门或引脚，在画布上单击放置；从引脚拖拽即可画线，导线实时正交走线；开启仿真后单击输入引脚切换电平，整条组合逻辑通路随之求值，导线按电平着色。

## 功能特性

**元件与电路**

- 8 种逻辑门：与、或、非、与非、或非、异或、同或、缓冲器；门的输入数量 1–8 可在属性面板调整
- 输入 / 输出引脚：输入引脚是驱动电平的开关，输出引脚是显示电平的探针
- 多电路工程：一个工程可包含多个电路，左侧树双击切换编辑；电路可添加、上移 / 下移、设为主电路、移除
- 子电路封装（自定义元件）：工程内任一电路都可作为元件实例化——实例以边框盒绘制，引脚按定义自动排布在盒子边缘；双击自定义元件进入其定义编辑（"打开黑盒"）；删除定义电路时同步清理所有实例，并给出提示
- 仿真求值支持子电路嵌套展开（最大深度 8），自引用或定义丢失时显示"坏框"而不是静默失效

**布线交互（对齐 Logisim 语义）**

- 从引脚按下拖拽即开始走线：路径跟随鼠标，变向处自动打拐点、原路返回自动取消拐点，松手收尾；预览 rubber band 与实际落线完全一致
- 单击引脚进入"粘滞"走线：不按键也能继续，每单击一处打一个拐点，点到引脚 / 既有导线 / 空白处收尾（双击或 Enter 就地收尾，Backspace 退掉最后一个拐点）
- 自动拐点避让其它元件外框（避障正交布线），导线不会从元件身体下面穿过
- 连接规则（Logisim）：只有端点相接、端点接入另一根导线中段（T 形）或共线重叠才算电气连接；两根导线单纯交叉**不**连通；在交叉点双击可显式放置连接点强制连通
- 移动元件时相连导线自动重铺拉伸（WireRepair），拉伸而不断裂；拖拽未选中导线 = 从该点分支布线，单击 = 选中，选中后拖拽 = 整条移动，拖拽端点 = 拉伸 / 缩短 / 转向

**仿真**

- 组合逻辑求值：未知值（X）传播、多驱动冲突检测
- 启用仿真 / 重置 / 单步；输入引脚用电平工具单击切换；仿真时高电平绿色、低电平蓝色、未知灰色

**编辑与视图**

- 选择、移动、框选、复制 / 剪切 / 粘贴 / 创建副本、删除、全选
- 撤销 / 重做（`Ctrl+Z` / `Ctrl+Y`）
- 文本标签；属性面板编辑标签、输入数量、引脚电平
- 缩放 25%–400%（滚轮以光标下网格点为中心）、中键拖拽平移、导出 PNG 图像
- 会话自动保存：关闭程序再打开，工作现场（含自定义元件）不丢失

## 构建

依赖：

- wxWidgets 3.2.x（本机路径 `F:\EDA\basic\basic_tools\wxWidgets-3.2.2.1`，见 `Project1.vcxproj` 中的 `WX_ROOT` 属性）
- Visual Studio 2022（平台工具集 v145）与 Windows SDK 10，x64

用 Visual Studio 打开 `Project1.slnx`，选择 `x64` + `Debug`/`Release` 生成并运行；也可以在开发者命令提示符中执行：

```bash
msbuild Project1.slnx /p:Configuration=Release /p:Platform=x64
```

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `eda.h` / `eda.cpp` / `noname.h` | wxFormBuilder 生成的 GUI 框架（菜单栏、工具栏、左侧面板、属性网格），**不手工修改** |
| `mainframe.h` / `mainframe.cpp` | `MainFrame`：把编辑内核挂到生成框架的各个控件上（画布、元件树、工具栏、菜单、属性表、左侧按钮）；管理多电路工程、会话保存、文件打开 / 保存 / 导出、电路统计 |
| `model.h` / `model.cpp` | 与 GUI 无关的数据模型：`Circuit` / `Component` / `Wire` / `Port`、20 像素网格、组合逻辑求值（含子电路展开）、工程序列化 |
| `canvas.h` / `canvas.cpp` | `CircuitCanvas`：绘制与全部鼠标 / 键盘交互——工具、走线、选中、移动修复、撤销重做、缩放、PNG 导出 |
| `wirenet.h` / `wirenet.cpp` | 正交导线几何与电气网络提取：连接规则、最短正交走线、避障布线、WireRepair 位移重铺。只认识网格点与折线，不依赖 wxString / wxDC，可独立测试 |

## 测试与验证

仓库根目录的 `_check/` 保存不依赖 GUI 交互的验证脚本（bash + MSVC）：

- `wirenet_check.sh`：编译并运行导线几何 / 建网模块的独立单元测试（配合 `stub/wx` 头文件桩，无需链接 wxWidgets）
- `model_check.sh`：编译并运行模型层冒烟测试（仅依赖 wxBase）
- `compile_check.sh` / `link_check.sh`：完整 GUI 程序的编译 / 链接检查
- `build_exe.sh`：以 Release 配置静态链接 wxWidgets，产出自包含可执行文件 `LogicSim.exe` 并放到桌面

## 工程文件格式

`.circ` 为 UTF-8 纯文本工程文件，包含工程内全部电路（子电路定义因此可以跨电路存活）。每个电路形如：

```
CIRCUIT main
NAME main
COMP 1 AND 4 4 2 0 标签
SUBNAME 2 半加器
WIRE -1 -1 3 0 2 4 5 4 6 1
TEXT 8 3 说明文字
JUNCTION 6 5
ENDCIRCUIT
```

- `COMP`：元件 id、类型令牌、网格坐标、输入数量、电平、标签
- `WIRE`：两端所在的元件 / 端口（-1 表示自由端）、点数、各点坐标、所属拖拽组
- `JUNCTION`：显式连接点（交叉强制连通）

旧版单电路文件（`EDA_CIRCUIT 1` 头）仍可正常打开。

## 设计约定（对齐 Logisim 源码语义）

- 一根 `Wire` 就是一段水平或垂直的导线（两个端点）；折线是多段相接的 `Wire`
- 电气网络（net）由 `wirenet.cpp` 从几何位置提取，而非记录在导线字段上
- 交叉规则：无端点重叠不相连；连接点（junction）显式放置
- 导线交互：未选中拖拽 = 分支 / 单击 = 选中 / 选中拖拽 = 移动；附属线缆可拉伸不断裂
