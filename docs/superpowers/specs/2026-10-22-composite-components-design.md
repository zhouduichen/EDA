# 组合式自定义元件设计

## 目标

允许用户把画布中选中的逻辑电路封装为可重复放置、可保存并可参与逻辑仿真的自定义元件。

## 用户流程

用户按住 Shift 点击选择多个元件，选择“创建自定义元件”，输入显示名称和类型标识。选区必须包含至少一个 `io.input` 和一个 `io.output`；它们分别作为组合元件的外部输入、输出端口。选区中的元件间连线成为内部实现。成功后，选区被一个新元件替换，已有选区外接线不允许被悄悄丢弃：若有连接跨越选区边界，创建操作报错并保留原电路。

## 架构

- `CompositeModule` 保存元件定义、内部原理图和外部端口到内部 IO 引脚的映射。
- `ComponentLibrary` 注册和枚举组合元件；画布用普通符号框绘制组合元件名称、输入/输出引脚和位号。
- `SchematicSnapshot` 携带随工程保存所需的组合元件定义。工程文件升至 CSEPROJ 3，保留 v1/v2 读取能力，并将每个组合元件的内部组件、导线和端口映射写入独立模块记录。
- `EditorController` 支持多选和封装动作：验证边界，注册模块，从主图移除选区内部元件/线，放入新组合元件；打开项目时先恢复模块定义，再加载主图。
- 仿真器把组合元件实例的输入电平映射到内部 `io.input`，递归运行内部快照，再将内部 `io.output` 电平映射到组合元件输出。首版禁止组合模块内部再包含组合元件，避免循环依赖和递归深度问题。

## 约束与失败处理

- 至少一个输入端口和一个输出端口。
- 输入/输出端口来自选区内 `io.input` / `io.output` 元件，端口顺序按从上到下排列。
- 每根与选区相关的导线必须完全位于选区内；跨界连接拒绝封装，并指出原因。
- 组合元件内部不能包含未知类型或其他自定义组合元件。
- 类型标识遵循现有 `namespace.name` 小写格式，重名时拒绝注册。
- 创建失败不改变主图或元件库。

## 测试

- 库能注册、查找和拒绝重复组合模块。
- 两输入 XOR/AND 等内部模块通过输入映射得到正确输出；X 值和冲突语义继承现有仿真器。
- 多选封装后主图只保留新实例；跨界线/缺少端口时安全拒绝。
- CSEPROJ 3 往返保存组合定义和内部电路，并保持 v1/v2 文件兼容。
